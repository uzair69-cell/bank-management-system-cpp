
# Bank Management System in C++

A beginner-friendly, console-based banking application developed using C++.

## Features
- Five-digit account ID validation
- Initial balance validation
- Deposit and withdrawal operations
- Insufficient balance checking
- Current and final balance display
- Object-oriented programming with encapsulation
- Method chaining using reference returns

## Concepts Used
- Classes and objects
- Private data members
- Constructors and member initializer lists
- Const member functions
- Input validation
- References and method chaining

## Technologies
- C++
- Standard C++ Library
- iostream and string

## How to Run

Compile the source file using a C++ compiler:

g++ BankManagement.cpp -o BankManagement

Run the compiled program:

Windows:
BankManagement.exe

## Project Scope
This project is designed for learning and demonstrating
C++ and OOP fundamentals. It is not a production banking
system and does not store account information permanently.
